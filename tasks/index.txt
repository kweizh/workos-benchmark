WorkOS Audit Logs lets you ingest user activity events for an organization and later export them as a CSV file using the Audit Log Export API. The Node.js SDK exposes two relevant methods:

- `workos.auditLogs.createExport({ organizationId, rangeStart, rangeEnd, ... })` — kicks off an asynchronous export job and returns an export object whose `state` starts as `pending`.
- `workos.auditLogs.getExport(id)` — fetches the current state of the export. Once `state` is `ready`, a short-lived `url` is returned that points to the generated CSV file.

Your job is to write a Node.js script that uses the official `@workos-inc/node` SDK to start an export for the last 24 hours, poll until the export is `ready`, and then download the CSV file to disk.

A pre-existing Node.js project lives at `/home/user/myproject` with the official `@workos-inc/node` SDK already installed (see `node_modules/@workos-inc/node/package.json`). The environment already provides `WORKOS_API_KEY` and `WORKOS_ORGANIZATION_ID`.

## Requirements
Implement a single Node.js script at `/home/user/myproject/index.js` that, when executed via `node index.js`:

1. Reads `WORKOS_API_KEY` and `WORKOS_ORGANIZATION_ID` from the environment and instantiates the SDK as `new WorkOS(process.env.WORKOS_API_KEY)`. If either env var is missing, exit non-zero.
2. Computes a 24-hour window:
   - `rangeEnd = new Date()` (now).
   - `rangeStart = new Date(rangeEnd.getTime() - 24 * 60 * 60 * 1000)` (24 hours ago).
3. Calls `workos.auditLogs.createExport({ organizationId: process.env.WORKOS_ORGANIZATION_ID, rangeStart, rangeEnd })` exactly once to start the export.
4. Captures the returned export object's `id` and writes a JSON document to `/home/user/myproject/export.json` with the following exact top-level fields:
   - `exportId` — the `id` returned by `createExport`.
   - `state` — the final state observed after polling (must be `"ready"`).
   - `url` — the signed download URL returned by `getExport` once `state === "ready"`.
   - `rangeStart` — ISO-8601 string for `rangeStart`.
   - `rangeEnd` — ISO-8601 string for `rangeEnd`.
5. Polls `workos.auditLogs.getExport(exportId)` until `state === "ready"`:
   - Sleep at least 2 seconds between polls.
   - Time out after 5 minutes (300 seconds) and exit non-zero if the export never becomes `ready`.
6. Once `ready`, downloads the export contents from the returned `url` (e.g. with `fetch` or `https.get`) and writes the raw response body to `/home/user/myproject/audit.csv`. The file must exist and be readable. If the export is empty for the time window, an empty (zero-byte) file is acceptable; what matters is that the script wrote whatever the URL returned.
7. Logs progress to stdout and exits with status code `0` on success, non-zero on failure.

3. Author `index.js` (CommonJS — `package.json` already uses CommonJS). A typical shape:
   ```javascript
   const fs = require('fs');
   const { WorkOS } = require('@workos-inc/node');

   async function sleep(ms) { return new Promise((r) => setTimeout(r, ms)); }

   async function main() {
     const apiKey = process.env.WORKOS_API_KEY;
     const organizationId = process.env.WORKOS_ORGANIZATION_ID;
     if (!apiKey || !organizationId) {
       console.error('WORKOS_API_KEY and WORKOS_ORGANIZATION_ID must be set');
       process.exit(1);
     }
     const workos = new WorkOS(apiKey);
     const rangeEnd = new Date();
     const rangeStart = new Date(rangeEnd.getTime() - 24 * 60 * 60 * 1000);

     const created = await workos.auditLogs.createExport({
       organizationId,
       rangeStart,
       rangeEnd,
     });
     const exportId = created.id;
     console.log(`created export ${exportId}, initial state=${created.state}`);

     const deadline = Date.now() + 5 * 60 * 1000;
     let current = created;
     while (current.state !== 'ready') {
       if (Date.now() > deadline) {
         console.error(`export ${exportId} never reached ready (last state=${current.state})`);
         process.exit(2);
       }
       await sleep(3000);
       current = await workos.auditLogs.getExport(exportId);
       console.log(`polled export ${exportId}, state=${current.state}`);
     }

     const url = current.url;
     const res = await fetch(url);
     if (!res.ok) {
       console.error(`download failed with status ${res.status}`);
       process.exit(3);
     }
     const buf = Buffer.from(await res.arrayBuffer());
     fs.writeFileSync('/home/user/myproject/audit.csv', buf);

     fs.writeFileSync(
       '/home/user/myproject/export.json',
       JSON.stringify({
         exportId,
         state: current.state,
         url,
         rangeStart: rangeStart.toISOString(),
         rangeEnd: rangeEnd.toISOString(),
       }, null, 2),
     );
     console.log('done');
   }

   main().catch((err) => { console.error(err); process.exit(1); });
   ```
