# Deactivate an Existing WorkOS Organization Membership ## Background A WorkOS organization membership represents a user's relationship to a specific organization. Memberships have a `status` of `active`, `inactive`, or `pending`. The WorkOS Node SDK exposes `workos.userManagement.deactivateOrganizationMembership(id)` (which targets `PUT /user_management/organization_memberships/:id/deactivate`) to transition an `active` membership to `inactive`. In this task you will write a small Node.js script that deactivates a specific organization membership using the WorkOS Node SDK and persists the returned membership object to disk. ## Requirements 1. The project lives at `/home/user/myproject`. It already has `package.json` with the `@workos-inc/node` SDK installed. 2. Implement a script at `/home/user/myproject/deactivate_membership.js` that: - Reads `WORKOS_API_KEY` and `WORKOS_ORG_MEMBERSHIP_ID` from the process environment. - Initializes the WorkOS client with `const workos = new WorkOS(process.env.WORKOS_API_KEY)`. - Calls `workos.userManagement.deactivateOrganizationMembership(process.env.WORKOS_ORG_MEMBERSHIP_ID)`. - Writes the JSON serialization of the returned organization membership object to `/home/user/myproject/membership.json` (pretty-printed with 2-space indentation). 3. Run the script with `node deactivate_membership.js` so that `/home/user/myproject/membership.json` exists after the run. ## Implementation Guide 1. `cd /home/user/myproject` 2.
