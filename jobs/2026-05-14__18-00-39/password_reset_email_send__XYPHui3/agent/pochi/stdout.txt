# Trigger a WorkOS Password Reset for a Test User ## Background WorkOS User Management exposes a Password Reset flow that lets you initiate a password reset for an existing user. In the current `@workos-inc/node` SDK (v8.x), the entry point is: ```js const passwordReset = await workos.userManagement.createPasswordReset({ email }); ``` This call creates a one-time password reset token, surfaces a `passwordResetUrl` your app can email to the user, and emits a `password_reset.created` event in WorkOS. The returned object looks like: ```json { "object": "password_reset", "id": "password_reset_01HYGD...", "userId": "user_01...", "email": "someone@example.com", "passwordResetToken": "...", "passwordResetUrl": "https://your-app.com/reset?token=...", "expiresAt": "...", "createdAt": "..." } ``` In this task you must build a small Node.js script that triggers this real password-reset flow against the **live** WorkOS API and records the outcome in a log file. On success (i.e. the returned object has an `id` that starts with `password_reset_`), append a single line to `/home/user/myproject/output.log` in this exact format: ``` SUCCESS password_reset_id=<id> email=<email> ``` followed by a second line containing the full returned object serialized as compact JSON: ``` OBJECT <json> ``` where `<id>` is `passwordReset.id`, `<email>` is `passwordReset.email`, and `<json>` is `JSON.stringify(passwordReset)`. 5.
